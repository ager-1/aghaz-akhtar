Unreal Engine / Blueprints / OpenXR

Room VR Walkthrough

An interactive, high-fidelity architectural walkthrough built entirely in Unreal Engine using Blueprints, optimized for PCVR and desktop platforms via the OpenXR framework.

Thinking Process / Behind the Build

The core philosophy was to move beyond static architectural visualization and build a living, responsive environment. By leveraging Unreal Engine and OpenXR, the goal was to craft a seamless PCVR experience where users actively influence the space rather than just observe it. Automating smart lighting based on the sun's position and building precise raycast interactions for the furniture ensures the environment feels intuitive and tactile. The focus was on prioritizing deep user immersion and comfortable seated navigation to create a highly polished interactive showcase.

AR / Prototype

AR VPS Application - Prototype

A prototype demonstration of the AR Visual Positioning System (VPS) application using MultiSet SDK and Unity.

Thinking Process / Behind the Build

Building this mobile augmented reality prototype was a rapid dive into advanced spatial computing and problem solving. I challenged myself to condense the five calendar days time box into an intense two day sprint without sacrificing core stability. The biggest hurdle was aligning the physics based NavMesh in Unity with the dynamic coordinate shifts of the MultiSet SDK. By decoupling the AI agent and forcing the system to rebake the invisible floor at runtime, I engineered a robust application that seamlessly handles tracking loss and successfully attempts to recover without requiring the application to be restarted. The end result effectively replaces the cognitive burden of mental translation with direct visual guidance.
